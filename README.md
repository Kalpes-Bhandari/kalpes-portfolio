# Kalpes Bhandari — Portfolio

Static site (HTML/CSS/JS, no build step). Deploys to Vercel as-is.

- **Add a project:** edit the `PROJECTS` array at the top of `script.js`.
- **Contact form:** paste your Web3Forms access key into `WEB3FORMS_KEY` in `script.js` (get one free at https://web3forms.com).
- **Preview locally:** `python3 -m http.server 5173`, then open http://localhost:5173
